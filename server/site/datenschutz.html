2. Lokale Verarbeitung von Bildern

RAW Select liest Bilder aus Ordnern, von Speicherkarten und von anderen Datenträgern, die du auswählst. Die Verarbeitung und Anzeige der Bilder erfolgt lokal auf deinem Mac.

Markierungen und Sitzungsdaten speichert die App unter ~/Library/Application Support/RAW Select, Einstellungen in ~/Library/Preferences/ch.anneler.rawselect.plist. Vorschaubilder können vorübergehend im lokalen Cache des Macs gespeichert werden. Diese Daten werden nicht an vfxmedia.ch oder einen anderen von mir betriebenen Dienst übertragen.

3. Update-Prüfung

Beim Start fragt RAW Select über die GitHub-API ab, ob eine neue Version verfügbar ist. Bei dieser Verbindung erhält GitHub technisch bedingt unter anderem die IP-Adresse des verwendeten Internetanschlusses. GitHub wird von GitHub, Inc. mit Sitz in den USA betrieben, die Daten können dort bearbeitet werden. Für die Verarbeitung durch GitHub gelten die Datenschutzbestimmungen von GitHub.

Ich erhalte durch die Update-Prüfung keine Bild-, Benutzer- oder Gerätedaten. Eine Update-Datei wird nur geladen, wenn du den Download bestätigst.

4. Keine Nutzungsstatistik

Ab Version 2.0 sammelt RAW Select keine Nutzungsdaten. Die App sendet keine Kennung, keine Versionsangaben und keine Angaben zu deinem Mac an vfxmedia.ch. Die einzige Verbindung, die sie von sich aus aufbaut, ist die Update-Prüfung bei GitHub (Abschnitt 3).

Ältere Versionen: Bis Version 2.0 Beta 1 hat RAW Select höchstens einmal pro Tag eine zufällig erzeugte Installationskennung, die App-Version und die Haupt- und Nebenversion von macOS an vfxmedia.ch übermittelt. Seit dem 21. Oktober 2026 nimmt der Server solche Meldungen noch an, speichert sie aber nicht mehr. Ältere Versionen senden sie weiter, bis du auf Version 2.0 aktualisierst.

Die bis dahin gespeicherten Einträge (Kennung, Version, macOS-Version, Datum, keine IP-Adressen) liegen weiterhin auf dem Server bei Hoststar in der Schweiz und werden nicht an Dritte weitergegeben. Auf Anfrage lösche ich die Einträge zu deiner Kennung innert 30 Tagen. Die Kennung findest du in älteren Versionen unter Einstellungen → Erweitert. Version 2.0 löscht sie beim ersten Start von deinem Mac. Ohne Kennung lässt sich ein Eintrag nicht zuordnen.

5. Download-Seite

Die Download-Seite setzt keine Cookies und verwendet kein Analyse- oder Werbenetzwerk. Schriften, Bilder und Seitenelemente werden direkt aus diesem Bereich von vfxmedia.ch geladen.

Beim Aufruf der Seite entsteht technisch eine Verbindung zum Webserver. Für Abrufe unter https://vfxmedia.ch/rawselect/ ist das Zugriffsprotokoll deaktiviert. Rufst du die Seite über eine unverschlüsselte http-Adresse auf, leitet der Server zuerst auf https um; diese Umleitung wird wie auf der Hauptseite protokolliert. Beim Klick auf «RAW Select herunterladen» erhöht der Server einen Zähler um eins. Gespeichert wird nur die Gesamtzahl pro Tag, ohne IP-Adresse, ohne Cookie und ohne weitere Angaben zu dir. Anschliessend wirst du zur Datei auf GitHub weitergeleitet. GitHub zählt ebenfalls, wie oft eine Datei geladen wurde, und zeigt diese Zahl öffentlich an. Ab diesem Zeitpunkt gelten auch die Datenschutzbestimmungen von GitHub.

6. Weitere Datenübertragungen

RAW Select überträgt keine Bilder, Dateinamen, Dateipfade, Markierungen, EXIF-Daten, Standortdaten oder Absturzberichte. Die App verwendet kein Benutzerkonto und keine Cloud-Synchronisierung. Wenn du die App vollständig entfernen willst, lösche zusätzlich die Datei ~/Library/Preferences/ch.anneler.rawselect.plist und den Ordner ~/Library/Application Support/RAW Select.

7. Kontakt per E-Mail

Wenn du mir schreibst, zum Beispiel über Hilfe → Feedback senden, bearbeite ich deine E-Mail-Adresse und den Inhalt deiner Nachricht, um sie zu beantworten. Die Feedback-Vorlage enthält die Version von RAW Select und von macOS. Bei einer Löschanfrage zu älteren Statistikeinträgen nutze ich die genannte Kennung nur, um die zugehörigen Einträge zu löschen. E-Mails bewahre ich auf, solange es für die Bearbeitung nötig ist.

8. Rechte und Kontakt

Du kannst Auskunft über die Bearbeitung deiner Personendaten sowie deren Berichtigung oder Löschung verlangen. Soweit die DSGVO anwendbar ist, können zusätzliche Rechte auf Einschränkung der Verarbeitung, Datenübertragbarkeit und Widerspruch bestehen.

Für Fragen zum Datenschutz oder zur Ausübung deiner Rechte erreichst du mich unter levin@annelers.ch. In der Schweiz ist der Eidgenössische Datenschutz- und Öffentlichkeitsbeauftragte (EDÖB) zuständig. Personen in der Europäischen Union können sich an die zuständige Datenschutzaufsichtsbehörde wenden.

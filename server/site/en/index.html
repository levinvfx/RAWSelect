RAW Select

RAW Select helps you cull large photo series quickly. You can mark shots, check sharpness at 100% and copy your selection to a destination folder or open it directly in Lightroom. The original files are never changed.

Opening RAW Select for the first time

Open the downloaded DMG file and drag RAW Select into the Applications folder. Because the app is not notarized by Apple, macOS blocks the first launch.

macOS 15 or later: Close the message with “Done”. Then open System Settings → Privacy & Security, scroll to the bottom, click “Open Anyway” next to RAW Select and confirm. macOS 14: Right-click RAW Select in the Applications folder, choose “Open” and confirm the dialog with “Open”. After that, the app starts normally.

RAW Select only downloads new versions after you confirm. Every update file is digitally signed, and the app checks this signature before opening it. Send feedback via Help → Send Feedback or to levin@annelers.ch.

RAW Select is free and provided without warranty. The app does not change any original files, but please back up your photos as usual.

Open a memory card or folder

External drives and memory cards appear automatically in the sidebar. Open a folder with ⌘O or drag it straight onto the window. Photos are loaded step by step, so you can start while they are still loading.

Review and mark photos

Use the arrow keys to move between photos. Keys 1 to 7 set a color mark, just like tags in the Finder: red, orange, yellow, green, blue, purple, gray. If you like, RAW Select then jumps straight to the next photo (Settings → Marks → “Jump to the next photo after marking”). On a marked photo, the same key or 0 removes the color mark again.

Check sharpness and details

Return opens the large view. Z switches to the 100% view, and the scroll wheel or a pinch on the trackpad zooms smoothly. The zoomed area stays in place as you move on, so you can compare similar shots at the same spot.

Copy or share your selection

Use the color filters to narrow down your selection. RAW Select then copies the original files and any XMP sidecars to the destination folder you choose. Files that already exist are not overwritten. The buttons at the top right open your selection in Lightroom, send it to Google Drive or show it in Finder.

Features

Focused on culling

Supported formats

RAW Select supports ARW, CR2, CR3, NEF, RAF, DNG, JPG, JPEG, HEIC and PNG. RAW and JPG files of the same shot can be shown as a single entry. Matching XMP files are assigned automatically.

Previews without interruption

RAW Select first shows a small preview and then replaces it with a sharper version. While you check a photo in the large view, the next one is prepared in the background.

Grid, list and large view

Photos can be shown as a grid, as a list or one at a time in the large view. In the list, click a column header to sort by name, date created, kind or size.

Original files stay untouched

Marks are stored in RAW Select and not written to the image files. The app does not change any files on memory cards. Move to Trash is only available for files on internal drives.

Select with color marks

The filter bar shows how many photos have each color. One click shows or hides a group. Hold the Option key ⌥ to show only the chosen group.

Updates only when you confirm

RAW Select checks for a new version at launch. You decide whether to download it. The app never installs updates automatically and only opens files with a valid signature.

Data processing

What RAW Select connects to

Your photos are processed only on your Mac. Photos, file names, paths, marks and EXIF data are not sent to any server. The app collects no usage data. It only connects to the network to check for updates.

Update check via GitHub

At launch, RAW Select asks GitHub for the current version number. A new version is only downloaded after you confirm, and its signature is checked before it opens.

Only downloads are counted

The server counts how often RAW Select is downloaded in full, at most once per person per day. Only one number per day and app version is stored, with no IP address and no cookie. The app itself sends no identifier and no usage data.

Nothing else is sent

RAW Select uses no user account, no cloud sync, no usage statistics, no ads and no crash reports. The download page sets no cookies and uses no external analytics tool.

2. Lokale Verarbeitung von Bildern

RAW Select liest Bilder aus Ordnern, von Speicherkarten und von anderen Datenträgern, die du auswählst. Die Verarbeitung und Anzeige der Bilder erfolgt lokal auf deinem Mac.

Markierungen und Sitzungsdaten speichert die App unter ~/Library/Application Support/RAW Select, Einstellungen und die Installationskennung (siehe Abschnitt 4) in ~/Library/Preferences/ch.anneler.rawselect.plist. Vorschaubilder können vorübergehend im lokalen Cache des Macs gespeichert werden. Diese Daten werden nicht an vfxmedia.ch oder einen anderen von mir betriebenen Dienst übertragen.

3. Update-Prüfung

Beim Start fragt RAW Select über die GitHub-API ab, ob eine neue Version verfügbar ist. Bei dieser Verbindung erhält GitHub technisch bedingt unter anderem die IP-Adresse des verwendeten Internetanschlusses. GitHub wird von GitHub, Inc. mit Sitz in den USA betrieben, die Daten können dort bearbeitet werden. Für die Verarbeitung durch GitHub gelten die Datenschutzbestimmungen von GitHub.

Ich erhalte durch die Update-Prüfung keine Bild-, Benutzer- oder Gerätedaten. Eine Update-Datei wird nur geladen, wenn du den Download bestätigst.

4. Nutzungsstatistik

RAW Select übermittelt höchstens einmal innerhalb von 24 Stunden folgende Angaben an vfxmedia.ch:

  • eine zufällig erzeugte und dauerhaft lokal gespeicherte Installationskennung
  • die verwendete Version von RAW Select
  • die Haupt- und Nebenversion von macOS

Der Server speichert diese Angaben zusammen mit dem Datum des Empfangs.

Die Installationskennung wird nicht aus Hardwaredaten erzeugt und nicht mit einem Namen, einer E-Mail-Adresse, einem Benutzerkonto, Bilddaten oder Dateipfaden verbunden. Sie ermöglicht jedoch, dieselbe Installation über mehrere Tage wiederzuerkennen. Deshalb bezeichne ich sie als pseudonyme und nicht als vollständig anonyme Kennung. Deine Kennung siehst du in der App unter Einstellungen → Erweitert.

Der Server wird bei Hoststar in der Schweiz betrieben. Für diesen Bereich ist die Speicherung von IP-Adressen im Webserver-Zugriffsprotokoll deaktiviert. Zweck der Statistik ist, die Anzahl aktiver Installationen und die Verteilung der App-Versionen zu ermitteln. Die Daten werden nicht an Dritte weitergegeben.

Speicherdauer: Eine automatische Löschfrist gibt es derzeit nicht. Die Einträge bleiben gespeichert, solange ich die Statistik führe, damit sich Nutzerzahlen über die Zeit vergleichen lassen. Auf Anfrage lösche ich alle Einträge zu deiner Kennung innert 30 Tagen. Startest du RAW Select danach wieder mit derselben Kennung, entstehen neue Einträge.

Die Statistik ist fester Bestandteil der App und lässt sich nicht abschalten. Wenn du der künftigen Erfassung widersprichst, lässt sich das nur umsetzen, indem du die App nicht mehr verwendest und die lokale Kennung löschst (siehe Abschnitt 6). Falls für diese Verarbeitung die DSGVO anwendbar ist, stützt sie sich auf das berechtigte Interesse, Nutzung und Versionsverteilung der kostenlos angebotenen App in möglichst geringem Umfang zu erfassen (Art. 6 Abs. 1 lit. f DSGVO).

5. Download-Seite

Die Download-Seite setzt keine Cookies und verwendet kein Analyse- oder Werbenetzwerk. Schriften, Bilder und Seitenelemente werden direkt aus diesem Bereich von vfxmedia.ch geladen.

Beim Aufruf der Seite entsteht technisch eine Verbindung zum Webserver. Für Abrufe unter https://vfxmedia.ch/rawselect/ ist das Zugriffsprotokoll deaktiviert. Rufst du die Seite über eine unverschlüsselte http-Adresse auf, leitet der Server zuerst auf https um; diese Umleitung wird wie auf der Hauptseite protokolliert. Beim Klick auf «RAW Select herunterladen» wird der Download als Gesamtzahl pro Tag gezählt. Anschliessend wirst du zur Datei auf GitHub weitergeleitet. Ab diesem Zeitpunkt gelten auch die Datenschutzbestimmungen von GitHub.

6. Weitere Datenübertragungen

RAW Select überträgt keine Bilder, Dateinamen, Dateipfade, Markierungen, EXIF-Daten, Standortdaten oder Absturzberichte. Die App verwendet kein Benutzerkonto und keine Cloud-Synchronisierung. Die Kennung bleibt in den Einstellungen deines Macs gespeichert, auch wenn du die App löschst, und wird bei einer erneuten Installation weiterverwendet. Entfernen kannst du sie, indem du die Datei ~/Library/Preferences/ch.anneler.rawselect.plist löschst oder im Terminal defaults delete ch.anneler.rawselect ausführst. Bereits übermittelte Statistikeinträge bleiben auf dem Server, bis du ihre Löschung verlangst.

7. Kontakt per E-Mail

Wenn du mir schreibst, zum Beispiel über Hilfe → Feedback senden, bearbeite ich deine E-Mail-Adresse und den Inhalt deiner Nachricht, um sie zu beantworten. Die Feedback-Vorlage enthält die Version von RAW Select und von macOS. Bei einer Löschanfrage nutze ich die mitgesendete Kennung nur, um die zugehörigen Einträge zu löschen. E-Mails bewahre ich auf, solange es für die Bearbeitung nötig ist.

8. Rechte und Kontakt

Du kannst Auskunft über die Bearbeitung deiner Personendaten sowie deren Berichtigung oder Löschung verlangen. Soweit die DSGVO anwendbar ist, können zusätzliche Rechte auf Einschränkung der Verarbeitung, Datenübertragbarkeit und Widerspruch bestehen.

Die Nutzungsstatistik ist nicht mit Namen oder Kontaktdaten verbunden. Einen Eintrag kann ich deshalb nur zuordnen, wenn du mir deine Kennung nennst. Am einfachsten geht das in der App unter Einstellungen → Erweitert → «Löschung meiner Daten verlangen»: Die vorbereitete E-Mail enthält deine Kennung bereits.

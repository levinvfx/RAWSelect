**Abschalten:** Unter Einstellungen → Erweitert → Statistik kannst du die Zählung ausschalten. Dann sendet die App nichts.

An den Funktionen ändert sich nichts.

Läuft etwas nicht rund, schreib mir über Hilfe → Feedback senden.

— English —

RAW Select 2.2.2

**Installations are counted:** Once per version, RAW Select now sends a random number and the version number to vfxmedia.ch. This shows me how many installations there are. Nothing else is sent: no photos, no file names, no details about your Mac. The server does not store the number itself, only a check value calculated from it.

**Turning it off:** You can switch the count off under Settings → Advanced → Statistics. The app then sends nothing.

The features are unchanged.

If something does not work as expected, write to me via Help → Send Feedback.

RAW Select

RAW Select hilft dir, grosse Bildserien schnell zu sichten. Du kannst Aufnahmen markieren, bei 100 % auf Schärfe prüfen, miteinander vergleichen und die Auswahl in einen Zielordner kopieren. Die Originaldateien werden dabei nicht verändert.

RAW Select zum ersten Mal öffnen

Öffne die geladene DMG-Datei und ziehe RAW Select in den Ordner «Programme». Da die App nicht von Apple notarisiert ist, blockiert macOS den ersten Start.

macOS 15 oder neuer: Schliesse die Meldung mit «Fertig». Öffne danach Systemeinstellungen → Datenschutz & Sicherheit, klicke ganz unten bei RAW Select auf «Dennoch öffnen» und bestätige. macOS 14: Klicke RAW Select im Programme-Ordner mit der rechten Maustaste an, wähle «Öffnen» und bestätige den Dialog mit «Öffnen». Danach startet die App normal.

Neue Versionen lädt RAW Select nur nach deiner Bestätigung. Jede Update-Datei ist digital signiert, die App prüft diese Signatur vor dem Öffnen. Rückmeldungen gehen über Hilfe → Feedback senden oder an levin@annelers.ch.

RAW Select ist kostenlos und wird ohne Gewähr bereitgestellt. Die App verändert keine Originaldateien, sichere deine Bilder trotzdem wie gewohnt.

Speicherkarte oder Ordner öffnen

Externe Datenträger und Speicherkarten erscheinen automatisch in der Seitenleiste. Einen Ordner öffnest du mit ⌘O oder ziehst ihn direkt auf das Fenster. Die Bilder werden schrittweise eingelesen, du kannst also schon während des Ladens beginnen.

Bilder sichten und markieren

Mit den Pfeiltasten wechselst du zwischen den Bildern. Die Tasten 1 bis 7 setzen einen Farbpunkt, wie die Tags im Finder: Rot, Orange, Gelb, Grün, Blau, Violett, Grau. Danach springt RAW Select zum nächsten Bild (in den Einstellungen abschaltbar). Auf einem markierten Bild entfernt dieselbe Taste oder 0 den Farbpunkt wieder.

Schärfe und Bilddetails prüfen

Return öffnet die grosse Ansicht. Mit Z wechselst du zur 100-%-Ansicht, mit dem Mausrad oder per Pinch auf dem Trackpad zoomst du stufenlos. Der Bildausschnitt bleibt beim Weiterblättern erhalten, damit sich ähnliche Aufnahmen an derselben Stelle vergleichen lassen.

Auswahl kopieren

Über die Farbfilter grenzt du deine Auswahl ein. Anschliessend kopiert RAW Select die Originaldateien und vorhandene XMP-Sidecars in den gewählten Zielordner. Bereits vorhandene Dateien werden nicht überschrieben.

Funktionen

Auf das Sichten konzentriert

Unterstützte Bildformate

Unterstützt werden ARW, CR2, CR3, NEF, RAF, DNG, JPG, JPEG, HEIC und PNG. RAW- und JPG-Dateien derselben Aufnahme können als ein gemeinsamer Eintrag angezeigt werden. Passende XMP-Dateien werden automatisch zugeordnet.

Vorschauen ohne Unterbruch

RAW Select zeigt zuerst eine kleine Vorschau und ersetzt sie danach durch eine schärfere Version. Beim Prüfen in der grossen Ansicht wird das nächste Bild im Hintergrund vorbereitet.

Zwei Bilder vergleichen

Im Vergleichsmodus stehen zwei Aufnahmen nebeneinander, der Zoom ist synchronisiert. Mit C startest oder beendest du den Vergleich, Return übernimmt das rechte Bild als neue Referenz.

Originaldateien bleiben unverändert

Markierungen werden in RAW Select gespeichert und nicht in die Bilddateien geschrieben. Auf Speicherkarten verändert die App keine Dateien. Die Papierkorb-Funktion steht nur für Dateien auf internen Laufwerken zur Verfügung.

Auswahl mit Farbmarkierungen

Die Filterleiste zeigt, wie viele Bilder jeder Farbe zugeordnet sind. Ein Klick blendet eine Gruppe ein oder aus. Mit gedrückter Wahltaste ⌥ zeigst du nur die gewählte Gruppe an.

Manuell bestätigte Updates

RAW Select prüft beim Start, ob eine neue Version verfügbar ist. Du entscheidest selbst, ob sie geladen wird. Die App installiert keine Updates automatisch und öffnet nur Dateien mit gültiger Signatur.

Datenverarbeitung

Welche Verbindungen RAW Select herstellt

Die Bilder selbst werden ausschliesslich auf deinem Mac verarbeitet. Bilder, Dateinamen, Pfade, Markierungen und EXIF-Daten werden nicht an einen Server übertragen. Die App sammelt keine Nutzungsdaten. Eine Netzwerkverbindung stellt sie nur für die Update-Prüfung her.

Update-Prüfung über GitHub

Beim Start fragt RAW Select bei GitHub nach der aktuellen Versionsnummer. Eine neue Version wird nur nach deiner Bestätigung geladen und vor dem Öffnen anhand ihrer Signatur geprüft.

Nur Downloads werden gezählt

Auf dieser Seite zählt der Server, wie oft «Herunterladen» geklickt wird. Gespeichert wird nur eine Zahl pro Tag, ohne IP-Adresse und ohne Cookie. Die App selbst sendet keine Kennung und keine Nutzungsdaten.

Keine weiteren Übertragungen

RAW Select verwendet kein Benutzerkonto, keine Cloud-Synchronisierung, keine Nutzungsstatistik, keine Werbung und keine Absturzberichte. Die Download-Seite setzt keine Cookies und verwendet kein externes Analysewerkzeug.

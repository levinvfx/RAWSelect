2. Local processing of photos

RAW Select reads photos from folders, memory cards and other drives that you choose. The photos are processed and displayed locally on your Mac.

With Send to Google Drive, RAW Select copies photos into a folder of the Google Drive for desktop app on your Mac. RAW Select itself does not connect to Google. The upload is handled by Google's app, and Google's terms apply.

The app stores marks and session data in ~/Library/Application Support/RAW Select and settings in ~/Library/Preferences/ch.anneler.rawselect.plist. Preview images may be stored temporarily in the Mac's local cache. This data is not sent to vfxmedia.ch or to any other service I operate.

3. Update check

At launch, RAW Select uses the GitHub API to check whether a new version is available. For technical reasons, GitHub receives information through this connection, including the IP address of the internet connection used. GitHub is operated by GitHub, Inc., based in the USA, and the data may be processed there. Processing by GitHub is governed by GitHub's privacy statement.

The update check does not give me any image, user or device data. An update file is only downloaded if you confirm the download.

4. No usage statistics

From version 2.0, RAW Select does not collect any usage data. The app sends no identifier, no version information and no information about your Mac to vfxmedia.ch. The only connection it makes on its own is the update check with GitHub (section 3).

Older versions: Up to version 2.0 Beta 1, RAW Select sent a randomly generated installation identifier, the app version and the major and minor version of macOS to vfxmedia.ch at most once a day. Since 21 October 2026, the server still accepts such reports but no longer stores them. Older versions keep sending them until you update to version 2.0.

I deleted all entries stored up to that point (identifier, version, macOS version, date, no IP addresses) on 21 October 2026. Version 2.0 also removes the identifier from your Mac on first launch.

5. Download page

The download page sets no cookies and uses no analytics or advertising network. Fonts, images and page elements are loaded directly from this section of vfxmedia.ch.

Visiting the page technically creates a connection to the web server. Access logging is turned off for requests under https://vfxmedia.ch/rawselect/. If you open the page via an unencrypted http address, the server first redirects to https; this redirect is logged as on the main site. When you click “Download RAW Select”, you download the file directly from vfxmedia.ch. Once it has been transferred in full, the server increases that day's download count by one. So that several clicks by the same person on the same day only count once, the server creates a check value (SHA-256) from the IP address, browser identifier, date and a secret key. Without this key, the IP address cannot be derived from it. The IP address itself is not stored, and the check value is only kept until the end of the day, after which it is deleted. Only the total per day is kept permanently, with no cookie and no further information about you. If the file is ever unavailable on vfxmedia.ch, you are redirected to the file on GitHub. In that case GitHub counts the download and shows the number publicly, and GitHub's privacy statement applies.

6. Other data transfers

RAW Select does not transfer any photos, file names, file paths, marks, EXIF data, location data or crash reports. The app uses no user account and no cloud sync. To remove the app completely, also delete the file ~/Library/Preferences/ch.anneler.rawselect.plist and the folder ~/Library/Application Support/RAW Select.

7. Contact by email

If you write to me, for example via Help → Send Feedback, I process your email address and the content of your message in order to reply. The feedback template contains the version of RAW Select and of macOS. I keep emails for as long as needed to deal with them.

8. Your rights and contact

You can request information about the processing of your personal data and ask for it to be corrected or deleted. Where the GDPR applies, you may also have the right to restrict processing, to data portability and to object.

For questions about data protection or to exercise your rights, you can reach me at levin@annelers.ch. In Switzerland, the Federal Data Protection and Information Commissioner (FDPIC) is responsible. People in the European Union can contact their competent data protection supervisory authority.
